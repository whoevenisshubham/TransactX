# Experience V3 — hosted release

[Live demo](https://transactx-frontend.vercel.app) · [Product overview](../../README.md)

Experience V3 brings the payment kernel into coherent customer, merchant and
read-only operator workspaces, with light/dark themes, responsive workflows,
shareable receipts, merchant QR receiving and a contextual evidence investigator.

## Included

- Real shared demo-role access and Google OIDC. New private accounts start at
  zero; Google currently uses an External/Testing audience.
- Exact-money payment review, account-isolated offline intents and replay,
  scoped activity, operational projection and independently observed bank evidence.
- Saved reports with precise citation navigation, structured Gemini validation,
  durable request/token limits and evidence-summary fallback.
- A separate 192-record illustrative scenario library with eight guided stories.
- Curated product documentation, maintained API contracts and a cleaner repository
  without the redundant implementation prompt/execution pack.

## Deployment and evidence

The hosted application was verified at frontend `f7e432a` and backend `433011c`.
This repository-presentation release preserves those application sources,
configuration, financial data and deployment rollback. No new payment or provider
generation is required for its documentation/contract-path changes.

See the [delivery report](../next-gen/DELIVERY_REPORT.md) for source-specific CI,
browser, OAuth, offline and generated-report evidence. Fixture screenshots are
labelled product illustrations, not new live integration results.

## Boundaries

Synthetic money only; no real banks or UPI/NPCI integration. Shared demo activity
is public to other visitors and bounded by capacity limits. Free hosting can sleep
and provider free-tier availability can change. No paid fallback is configured.

This is a hosted-demo release. It does not certify a standalone native Linux
installation, a new native crash/restored-worker experiment, or scheduled backup
retention/RPO. Existing historical evidence keeps its original scope.
