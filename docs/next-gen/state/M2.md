- **Defect Analysis in Run #38506276054:**
  - CI test failure reported: `expected dropped spans count > 0 due to overload, got 0`.
  - Analysis showed that `ExportSpans` sanitizes each span individually before pushing to `e.queue`. Under race detector scheduling, the worker thread drained the queue of capacity 2 faster than `ExportSpans` could fill it, preventing overload from triggering.
  - This was a test-synchronization race, not a failure of non-blocking queue semantics.
- **Deterministic Synchronization Implementation:**
  - Added `ExporterOption` and `WithConsumerBarrier(barrier <-chan struct{})` in `backend/internal/telemetry/exporter.go`.
  - In `TestBoundedExporter_QueueOverloadNeverBlocks`, a test-controlled barrier channel holds the exporter worker from consuming spans during queue fill.
  - The test fills the bounded queue, deterministically triggers span drop, verifies non-blocking caller execution and exact dropped span count, and then closes the barrier to allow the worker to drain cleanly before shutdown.
  - No sleeps, no weakening of dropped span assertions, and no skipping under `-race`.
