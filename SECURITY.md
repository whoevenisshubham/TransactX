# Security Policy

## Reporting a Vulnerability

TransactX is a payment reliability simulation project. If you discover a security issue (for example, an authentication bypass, secret exposure, or injection vulnerability), please do **not** open a public GitHub issue.

Instead, report it privately to the repository maintainer via GitHub Security Advisories or direct contact.

## Scope

- Never post real credentials, JWTs, database URLs, or personal data in issues or pull requests.
- Demo accounts are shared synthetic identities; do not enter real financial or personal information.
